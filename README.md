
##cs events @ cornell 🎉##
your one place for all cornell CS opportunities — built in SwiftUI.

##what is this##
CSEvents is an iOS app for Cornell CS students to discover and track events happening around the CS community — workshops, hackathons, speaker panels, showcases, and more. instead of digging through listservs and discord servers, it's all in one place, sorted and ready.

##features##
📅 browse events: scroll through upcoming CS events with details on time, location, and who's going
🗂️ filter by category: tech workshops, hackathons, famous speakers, awards, and more
✅ track what you're attending: your personal "going" list, sorted earliest to latest using merge sort (yes, we implemented it from scratch)
👤 profile page: see your info, who you follow, and your event history


##tech stack##
SwiftUI — UI framework
Swift — language
No external dependencies — pure native iOS
